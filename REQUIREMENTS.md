1. The user shall be able to input a first number
2. The user shall be abe to select an operator (+,-,*,/)
3. The user shall be able to enter a second number
4. The user shall be able to read the result.

For the calculator to be complete, it must be able to perform calculations with any of the 4 operators accurately without error.

Example inputs:

3 + 5
Result: 8

80/4
Result: 20
